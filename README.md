# CDA Project

## Escape Room Suite

An interconnected monorepo with 3 apps: Web, Mobile, and Tablet. A Node/Express + Socket.io server. And Shared types, auth, and a theme.

**Assignment:** CDA Project
**Full Sail University**

Technologies used:

- [Turborepo](https://turborepo.dev/)
- React
- React Native
- Node & Express
- [Socket.io](https://socket.io/)
